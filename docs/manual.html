1. 系统简介

WebCamXT 是一款面向薄膜晶体管（TFT）I-V 测试数据的在线分析平台，采用浏览器/服务器（B/S）架构，无需安装客户端。主要功能：

  • 数据管理：上传 Excel 格式的 I-V 测试数据，多用户之间数据完全隔离；
  • 曲线绘制：绘制输出特性（Output，Id-Vd）与转移特性（Transfer，Id-Vg）曲线，支持线性/对数坐标、多曲线叠加对比；
  • 参数提取：一键自动拟合（Auto Fitting），提取阈值电压 Vth、场效应迁移率 UFE、亚阈值摆幅 SS；
  • TCAD 仿真：基于物理紧凑模型进行 I-V 仿真，支持接触电阻（RC）提取与仿真-实验对比误差评估。
推荐浏览器：Chrome / Edge 最新版。界面同时显示中英文时以本手册章节描述为准。

2. 快速开始：登录与注册

2.1 访问系统

在浏览器地址栏输入：http://10.102.35.1:8080

2.2 注册新账号（需要邀请码）

系统采用邀请码注册机制，邀请码由管理员生成发放。注册步骤：

  1. 打开登录页，点击「注册」；
  2. 填写用户名、密码、邮箱（选填）以及管理员提供的邀请码；
  3. 提交后自动登录并进入系统。
注意：每个邀请码只能使用一次，且有过期时间（默认 7 天），请及时使用。

2.3 登录

输入用户名和密码登录。登录凭证有效期为 24 小时，过期后会自动跳转到登录页，重新登录即可。

2.4 用户角色

角色权限
普通用户（user）上传/管理自己的数据文件，进行分析与仿真
管理员（admin）普通用户全部权限 + 生成/撤销邀请码、管理所有用户

3. 数据文件格式要求

系统通过 Excel 文件导入测试数据，上传前请确认文件满足以下要求，否则会解析失败：

项目要求
文件格式.xls 或 .xlsx，大小不超过 16 MB
工作表数据必须位于名为 Sheet1 的第一个工作表中
必需列名W（宽度 um）、L（长度 um）、TO（测试类型）、GateV（栅压 V）、DrainV（漏压 V）、DrainI（漏极电流 A）
TO 取值0 = 输出特性数据（固定 GateV，扫描 DrainV）；1 = 转移特性数据（固定 DrainV，扫描 GateV）
自动拟合要求所选 W/L 下至少要有 2 个不同 DrainV 的转移特性（TO=1）数据
同一文件可以包含多组 W/L 器件的数据；上传成功后系统会自动解析出可用的 W、L 及电压组合。

4. 文件管理（My Files）

登录后进入「My Files」页面，可进行：

  • 上传文件：点击「Upload File」选择 Excel 文件，上传成功后自动解析并出现在列表中；
  • 分析：点击某文件行的「Analyze」进入分析页面；
  • 删除：点击「Delete」并确认，文件及其数据将被彻底删除（不可恢复）。

列表显示文件名、大小和上传时间。每个用户只能看到和操作自己上传的文件。

5. 数据分析（Analysis）

分析页面分为三部分：顶部工具栏、左侧绘图区、右侧参数面板。点击文件列表的「Analyze」即可进入：

5.1 顶部工具栏

按钮作用
Plot按右侧 exp 区选定的参数，绘制实验曲线
Simulation打开仿真参数对话框，提交 TCAD 仿真（见第 6 节）
Auto Fitting对当前选定的 W/L 器件自动提取 Vth、UFE、SS
Append / Replace新曲线「叠加到」或「替换」现有曲线（用于多曲线对比）
Linear / Log纵轴线性 / 对数坐标切换
Delete All清空绘图区所有曲线

5.2 右侧参数面板 — exp（实验数据）

  1. 从下拉框依次选择 W(um)、L(um)；
  2. 选择曲线类型 Type：output（输出特性）或 transfer（转移特性）；
  3. 选择固定电压 Vgs（output 时）或对应偏置点（transfer 时）；
  4. 点击工具栏「Plot」绘制。

5.3 右侧参数面板 — sim（仿真范围）

设置仿真曲线的类型、W/L 以及扫描范围（Vgs Range、Vds Range、Step），该区域参数会与仿真对话框中的物理参数一起提交。

5.4 Curves 曲线列表

已绘制的曲线以列表管理：蓝色 Exp 标签为实验曲线，橙色 Sim 标签为仿真曲线；勾选框控制显示/隐藏，右侧删除按钮移除单条曲线。

5.5 Fitting Results 拟合结果

点击「Auto Fitting」后显示：

指标含义
V_th阈值电压（V）
U_FE_1线性区场效应迁移率（cm²/V·s）
U_FE_2饱和区场效应迁移率（cm²/V·s）
SS亚阈值摆幅（mV/dec）

6. TCAD 仿真参数说明

点击工具栏「Simulation」打开参数对话框，分为「物理参数」与「RC 设置」两部分：

6.1 物理参数（Physics Parameters）

参数含义默认值
T_tail (K)尾态特征温度348.17
T_deep (K)深能级特征温度580.28
g_tail尾态态密度5.1e18
g_deep深能级态密度2.463e18
T (K)测试温度（不可与 T_tail/T_deep 相等）300
mu_free自由载流子迁移率（cm²/V·s）0.8
Vfb (V)平带电压-0.8
phi_F0 (V)费米势参考值0.4
CoxArea单位面积氧化层电容0.03
Warp Effect (M)翘曲效应系数0.2

6.2 RC 设置

参数含义
Enable RC是否启用接触电阻提取（启用后仿真时间明显增加）
Max IterationsRC 迭代求解的最大次数（默认 100）
Error ToleranceRC 迭代收敛容差（默认 0.01）

6.3 仿真结果

仿真完成后曲线自动叠加到绘图区（Append 模式），可与实验曲线直观对比。同时返回拟合误差率 fitting_error_rate（仿真电流与实验电流的平均相对误差，0~1，越小越好）。启用 RC 时还会返回各偏置点的接触电阻数组。

参数约束：T_tail ≠ T、T_deep ≠ T；Step 必须 > 0。违反时系统会提示错误。

7. 管理员功能

管理员登录后导航栏会出现管理菜单：

7.1 邀请码管理（Invites）

  • 生成：点击生成邀请码，默认 7 天有效，可自定义有效天数；
  • 查看：列表显示所有邀请码的状态（未用/已用/已撤销）、使用人、过期时间；
  • 撤销：未使用的邀请码可撤销，撤销后无法再用于注册。

7.2 用户管理（Users）

  • 查看所有用户及其文件数量；
  • 调整角色（user ↔ admin）；
  • 删除用户（会同时删除其全部数据文件，且不能删除自己）。

8. 常见问题（FAQ）

问题原因与解决
提示「邀请码无效/已被使用/已过期」邀请码输错、已被他人使用或超过有效期，请联系管理员重新生成
上传提示「Invalid file type」只支持 .xls / .xlsx 格式
上传提示「文件解析失败」检查：数据是否在 Sheet1；是否包含 W/L/TO/GateV/DrainV/DrainI 六列且列名无误
提示「Width/Length value not found」所选 W/L 组合在数据文件中不存在，请在右侧下拉框中选择解析出的组合
页面突然跳回登录页登录凭证（24 小时）过期，重新登录即可，数据不会丢失
提示「无权访问此文件」每个用户只能访问自己上传的文件
仿真报 500 错误记录操作步骤与参数，通过第 9 节方式反馈给管理员

字段填写说明
提交人 / 日期姓名与提交日期
类型Bug（缺陷）或 建议（优化）
严重程度致命 / 严重 / 一般 / 轻微 / 建议
所在页面登录、文件管理、分析、仿真、管理后台等
操作步骤按顺序写出复现步骤（1、2、3…），越详细越好
期望结果 / 实际结果分别填写预期行为与实际发生的现象
截图粘贴截图或将截图文件命名为「编号-说明.png」
提 Bug 的黄金法则：能让别人按你的步骤一步步复现。请务必带上 W/L、参数取值和使用的测试文件。
